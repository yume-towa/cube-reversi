# キューブリバーシ

立方体の盤で遊ぶリバーシです。縦・横・奥行き・面の斜め・立体の対角線の **26方向** で相手の石を挟みます。
ビルド不要の HTML 1ファイル（`index.html`）で動きます。

## 遊び方

- 盤の大きさは **8×8×8（512マス）／6×6×6（216マス）／4×4×4（64マス）** から選べます。
- 黒が先手。中央の 2×2×2 に黒白4個ずつ、互い違いに置いて始めます。
- 26方向のどれかで相手の石を挟める場所に置けます。挟んだ石はすべて自分の色になります。
- 置ける場所がなければ自動でパス。両者とも置けなくなったら終局し、石の多いほうが勝ちです。

## 画面と操作

| 部分 | 内容 |
|---|---|
| 立方体ビュー | ドラッグで回転。金色の点が置ける場所で、タップで選択 |
| 断面盤 | 立方体を「水平（段）・前後（行）・左右（列）」で切った N×N の盤。タブで位置を選ぶ。タブの数字はその断面の候補数 |
| 着手 | 候補を1回タップすると返る石を金枠で表示。もう一度タップか「置く」で確定 |
| 相手の石をタップ | その石を返せる手を一覧表示（返る数の多い順、多いときは横にスクロール） |
| 状態欄 | 手番・候補数・返る数などを表示。高さは固定で、選択や手番が変わっても下の立方体・断面盤は動かない |
| 対戦 | あなた（黒）vs CPU ／ CPU（黒）vs あなた ／ ふたりで対戦 ／ CPU同士（観戦） |
| CPU同士 | 速さ（ゆっくり・ふつう・速い）、一時停止、停止中の一手戻し |
| 一手戻す | CPU対戦では自分の手番まで戻る |
| 結果画面 | 勝敗・石数、形勢（石差）の推移グラフ、角・辺・面・内部ごとの石、段ごとの石、最大返し数 |

キーボード: `[` / `]` で断面の位置を移動、`Esc` で選択解除・結果画面を閉じる。

## 仕組み（実装メモ）

- すべて `index.html` の中にあります（CSS・JavaScript とも埋め込み、外部ライブラリなし）。外部から読むのは Google Fonts だけです。
- 盤は長さ N³ の `Int8Array`（0=空、1=黒、2=白）。マス番号は `x + N*y + N*N*z`。
- `setSize(n)` で各マスから26方向への「レイ」を前計算し、`flipsAt` / `legal` で合法手と返る石を求めます。
- CPU（`cpuPick`）は1手読みの評価です。角・辺・面の位置の重み、角の内側マスの減点、相手の置ける数（着手可能数）を減らす手、終盤は返す数を重視。
- 立方体ビューは Canvas 2D による自前の透視投影（3Dライブラリは不使用）。
- 対局は `localStorage` のキー `hachi-reversi-v1` に保存（直近80手の履歴つき）。キー名は旧名「八立方リバーシ」の名残で、変えると保存済みの対局は読めなくなります。
- 配色はライト／ダーク両対応（`prefers-color-scheme` と `data-theme`）。
- 状態欄（`#status`）は上段 `.s1`・下段 `.s2` の2段で、各段の高さを固定しています（720px以上は横に並べて1段）。文が長いときは上段は「…」、下段は2行で打ち切り。中身を増やすときはこの高さに収まるか確認してください。

## 確認済みのこと

- 合法手・返る石の判定を、別実装と 4/6/8 の全サイズで約354万回突き合わせて一致。
- 着手、一手戻す、相手の石からの手選び、断面の向き切り替え、再読み込み後の復元、CPU同士の一時停止・再開、パス、空きマスを残した終局をブラウザで自動テスト。
- 360px幅（スマホ）〜PC幅、ライト・ダークで横はみ出しなし。
- 立方体ビューの点のタップ（マウス・タッチ）で選択→もう一度タップで着手できる。
- 状態欄のどの状態（候補選択・相手の石の一覧・CPU思考中・パス・一時停止・終局など）でも、立方体ビューと断面盤の位置が動かないことを 320〜1280px 幅で確認。
- 320px幅では、最初の1手の案内文の末尾だけ「…」で省略されます（360px以上は省略なし）。

## GitHub Pages で公開する

1. このフォルダの中身（`index.html`・`README.md`）をリポジトリ `cube-reversi` に置いて push。
2. GitHub のリポジトリで **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存。
3. 数分後に `https://<ユーザー名>.github.io/cube-reversi/` で遊べます。
